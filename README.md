# Blender Automobilista 2 Importer
Imports Automobilista 2 tracks and cars straight from the game’s .bff archives, with meshes, materials, textures, lights and liveries, so you don’t need to unpack anything first. Trees and other vegetation come in with proper alpha cutouts, and terrain shadow helper meshes are tucked away in their own hidden collection. Before your first import, open the add-on preferences and set the path to your Automobilista 2 install folder, otherwise shared textures like paint, carbon and glass will be missing.
